# Tauri v2 App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Tauri v2 GUI/mobile-ready app for `injera` while preserving the existing Rust CLI.

**Architecture:** Keep `injera` as the reusable Rust core, add preview-first rename APIs, then expose those APIs through a Tauri v2 backend. Build a Vite/TypeScript frontend that lets users choose a directory, preview sequence/regex rename results, and apply the plan.

**Tech Stack:** Rust 2024, Tauri 2.11.3, tauri-build 2.6.3, tauri-plugin-dialog 2.7.1, serde 1.0.228, Vite 8.1.0, TypeScript 6.0.3, @tauri-apps/api 2.11.1.

---

## File Structure

- `src/renamer.rs`: add serializable rename plan/report structs and preview/apply APIs; keep writer-based logging functions.
- `tests/renamer.rs`: add tests for preview and apply behavior.
- `Cargo.toml`: add serde dependency and workspace membership for `src-tauri`.
- `package.json`, `package-lock.json`, `index.html`, `tsconfig.json`, `vite.config.ts`: frontend build and Tauri script configuration.
- `src-ui/main.ts`, `src-ui/styles.css`, `src-ui/vite-env.d.ts`: GUI implementation.
- `src-tauri/Cargo.toml`, `src-tauri/build.rs`, `src-tauri/src/lib.rs`, `src-tauri/src/main.rs`, `src-tauri/tauri.conf.json`, `src-tauri/capabilities/default.json`: Tauri v2 app shell and command bridge.
- `README.md`, `README.ko.md`: document GUI build/dev commands and mobile preparation commands.

## Status

Completed. The clap CLI (`src/cli.rs`, `src/main.rs`, `tests/cli.rs`) was removed after this plan was
written; `injera` is now a library crate consumed by the `injera-app` Tauri crate, and the writer-based
`rename_by_*_with_writer` functions remain as the logging-capable entry points.

Verified with `cargo fmt --check`, `cargo clippy --workspace --all-targets -- -D warnings`,
`cargo test --workspace`, and `npm run build`.

Later work went past this plan: sequence prefix/start/padding options, per-entry selection in the
preview, and an in-app file browser (`src/browser.rs`) with folder navigation, multi-select, and
zip/cbz first-image thumbnails. The browser also replaces the native folder dialog on mobile, where
`tauri-plugin-dialog` cannot pick directories.
