# injera

[English](README.md) | [한국어](README.ko.md)

`injera`는 데스크탑과 모바일에서 사용할 수 있는 Tauri v2 기반 파일명 일괄 변경 앱입니다.

## 기능

- 네이티브 폴더 다이얼로그 없이 앱 안에서 폴더를 탐색합니다.
- 다중 선택으로 rename할 파일만 고르거나, 폴더 전체를 한 번에 선택합니다.
- `.zip`과 `.cbz`는 내부 첫 이미지를 썸네일로 보여줘 어떤 아카이브인지 알 수 있습니다.
- 낱장 이미지든 `.zip`/`.cbz` 내부 이미지든 재인코딩한 사본을 만들며, 원본은 그대로 둡니다.
- 마지막으로 보던 폴더를 다시 열어줍니다.
- 변경 작업을 적용하기 전에 전체 rename 결과를 미리 봅니다.
- 파일을 자연 정렬한 뒤 `00001.jpg` 같은 순번 이름으로 변경합니다.
- 순번 이름의 접두사, 시작 번호, 자릿수를 지정합니다.
- 정규식 pattern과 replacement로 파일명을 변경합니다.
- 미리보기에서 개별 파일의 선택을 해제해 그 파일만 그대로 둡니다.
- 중복 대상 이름이나 이미 막힌 대상 경로를 실행 전에 차단합니다.
- 같은 앱 코드로 데스크탑 패키지와 Android 모바일 산출물을 빌드합니다.

## 개발

JavaScript 의존성 설치:

```bash
npm install
```

데스크탑 앱 개발 모드 실행:

```bash
npm run tauri:dev
```

검증:

```bash
cargo fmt --check
cargo test --workspace
npm run build
```

## 탐색과 선택

앱은 홈 폴더에서 시작하며, 해당 폴더의 하위 폴더와 파일을 자연 정렬로 보여줍니다. 그래서
`scan-2.jpg`가 `scan-10.jpg`보다 먼저 나옵니다.

- **Up**과 **Home**으로 폴더를 이동하고, 폴더 행을 클릭하면 그 폴더로 들어갑니다.
- **Choose**는 데스크탑에서 네이티브 폴더 다이얼로그를 여는 단축 경로입니다.
- rename할 파일을 체크하거나 **Select all**을 누릅니다. 체크된 파일만 rename되며, 순번은 그
  파일들의 자연 정렬 순서를 따릅니다.
- 폴더를 이동하면 현재 선택과 미리보기가 초기화됩니다.

`.zip`과 `.cbz` 파일은 아카이브 내부를 자연 정렬한 첫 이미지를 읽어 썸네일로 보여줍니다. 이미지가
없거나 첫 이미지가 12MB를 넘는 아카이브는 기본 placeholder로 표시됩니다. 썸네일은 해당 행이 화면에
들어올 때만 읽습니다.

## 이미지 변환

**Convert** 모드는 선택한 대상마다 변환된 사본을 새로 쓰며, 원본은 건드리지 않습니다. 두 종류를
모두 처리합니다.

- **아카이브**(`.zip`, `.cbz`)는 내부 이미지를 전부 재인코딩한 사본으로 복제됩니다.
  `volume-1.cbz` → `volume-1-compressed.cbz`
- **이미지 파일**은 단독으로 재인코딩되며, 선택한 포맷의 확장자를 따릅니다.
  포맷이 JPEG면 `cover.png` → `cover-compressed.jpg`

둘을 함께 선택해도 됩니다. 그 외 파일은 대상에서 제외됩니다.

| 옵션 | 기본값 | 동작 |
| --- | --- | --- |
| Image format | Keep original | `Keep`은 각 이미지를 원래 포맷 그대로 재인코딩합니다. `JPEG`/`PNG`/`WebP`는 모든 이미지를 변환하며 엔트리 확장자도 함께 바뀝니다. |
| Quality | `80` | JPEG 품질(1-100). PNG와 WebP 출력은 무손실이라 해당 포맷에서는 비활성화됩니다. |
| Suffix | `-compressed` | 사본 이름을 만들 때 파일 stem 뒤에 붙습니다. 경로 구분자는 거부됩니다. |

이미지는 모든 코어를 써서 배치 단위로 변환하므로, 큰 아카이브도 전체를 메모리에 올릴 필요가 없습니다.
실행 중에는 이미지 단위로 진행률이 표시됩니다.

원본을 건드리지 않으므로 실행 후에도 선택이 유지됩니다. Quality나 Suffix만 바꿔 다시 Preview하면
같은 파일을 한 번 더 변환할 수 있습니다.

포맷을 `Keep`으로 두면 재인코딩 결과가 원본보다 커진 경우 그 결과를 버리고 원본 바이트를 유지합니다.
용량을 줄이려다 오히려 커지는 일이 없습니다. 포맷을 명시적으로 고르면 항상 변환합니다.

아카이브 안에서는 이미지가 아닌 엔트리를 바이트 그대로 복사하고, 디코딩할 수 없는 이미지는 아카이브
전체를 실패시키는 대신 원본 그대로 복사하며, 64MB를 넘는 엔트리는 디코딩 없이 복사합니다. 낱장
이미지가 디코딩되지 않으면 오류로 알립니다. 출력 이름이 이미 존재하거나 두 원본이 같은 이름으로
수렴하면 실행을 중단하므로 덮어쓰는 일은 없습니다.

## Sequence 옵션

Sequence 모드는 접두사, 번호, 원본 확장자를 조합해 이름을 만듭니다.

| 옵션 | 기본값 | 동작 |
| --- | --- | --- |
| Prefix | 없음 | 번호 앞에 붙는 문자열입니다(예: `photo-`). 경로 구분자는 거부됩니다. |
| Start number | `1` | 자연 정렬 기준 첫 파일에 부여할 번호입니다. |
| Padding | auto | 0 채움 자릿수입니다. auto는 최소 5자리를 쓰고, 가장 큰 번호가 들어가도록 늘어납니다. |

예를 들어 Prefix `photo-`, Start number `8`, Padding `3`이면 첫 파일은 `photo-008.jpg`가 됩니다.

## 파일 선택

미리보기의 모든 파일은 기본적으로 선택되어 있습니다. 특정 행의 체크박스를 해제하면 그 파일은 현재
이름을 유지하고, rename은 선택된 행에만 적용됩니다. 선택 해제된 파일도 그 이름을 계속 차지하므로,
해당 이름이 다른 파일의 대상이 되면 덮어쓰지 않고 오류로 알립니다.

## 데스크탑 빌드

데스크탑 패키지 빌드:

```bash
npm run tauri:build
```

Rolling Linux 배포판에서 AppImage 번들링 중 최신 ELF 섹션 strip이 실패하면 다음 명령을 사용하세요:

```bash
npm run tauri:build:linux
```

Linux 패키지는 다음 위치에 생성됩니다.

```text
target/release/bundle/
```

## Android 빌드

Android 프로젝트가 아직 생성되지 않았다면 초기화합니다.

```bash
npm run tauri:android:init
```

Android 산출물 빌드:

```bash
npm run tauri:android:build
```

unsigned APK와 AAB는 다음 위치에 생성됩니다.

```text
src-tauri/gen/android/app/build/outputs/
```

### Android 제약

`tauri-plugin-dialog`가 Android와 iOS의 디렉토리 다이얼로그에 대해 `FolderPickerNotImplemented`를
반환하기 때문에 **Choose** 버튼은 모바일에서 동작하지 않습니다. 모바일에서는 앱 내장 탐색기가
진입점입니다. 다만 Android scoped storage가 앱이 읽을 수 있는 폴더를 계속 제한하므로, 앱 자체
저장소 밖의 폴더는 플랫폼이 접근을 허용하기 전까지 읽히지 않을 수 있습니다.

## iOS 빌드

iOS는 macOS와 Xcode가 필요합니다. iOS toolchain이 설치된 macOS 환경에서 Tauri iOS 명령을 사용하세요.
